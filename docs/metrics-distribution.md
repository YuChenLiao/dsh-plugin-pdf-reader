## 校准观察（阶段 3 定阈值的依据）

样本构成：25 份 = 本地真实中文文档 5 + 公开英文论文（arXiv，多双栏）10 + 图像页 PDF 10（其中 4 份带噪点模拟扫描件）。

### 结论一：两类文本与图像页区分得很干净

| 指标 | 文本类（中文） | 文本类（英文） | 图像页 |
| --- | --- | --- | --- |
| `empty_page_ratio` | 0 – 0 | 0 – 0.01 | **1.0** |
| `avg_chars_per_line` | 12.7 – 44.3 | 79.3 – 274 | 0 |
| `replacement_ratio` | 0 | 0 | 0 |

图像页的 `empty_page_ratio` 恒为 1，`empty_page_ratio > 0.20` 这条阈值足以全部命中，且文本类最大值只有 0.01，余量 20 倍。`image_only_hint` 不需要再加权重。

### 结论二：任务书原阈值 `last_page_ratio < 0.10` 会误报

英文论文该指标 min = **0.0695**（末页是参考文献结尾，本来就短），中文文档 min = 0.1372。按原阈值会把正常论文判成"疑似截断"。

**改为 `< 0.05`**，并且只在该文档 `chars/pages ≥ 100`（不是扫描件）时才参与判定 —— 扫描件的 `last_page_ratio` 恒为 0，靠 `empty_page_ratio` 已经判掉了，重复计分没有意义。

### 结论三：`cjk_ratio` 的下限比预想的低

中文真实文档 5 份的 `cjk_ratio` 区间是 **0.378 – 0.719**（中位 0.65），因为简历/证明里混了大量数字、邮箱、英文公司名。原阈值 "全文 cjk_ratio < 0.30" 只有 1.26 倍余量，样本再变就可能误报。

**改为 `< 0.25`**，并且仍要求"首部 2000 字符 CJK ≥ 5%"作为前置条件（避免对纯英文文档误用这条）。

### 结论四：`single_char_line_ratio` 的余量偏薄

英文论文 max = 0.086（100 页那篇，目录与参考文献中有大量单项行）。原阈值 0.15 只有 1.7 倍余量。

**改为 0.30**，同时把 `line_end_punct_ratio` 一并记录（本批样本里中文 0.19–0.50、英文更低），用于阶段 3 交叉判断"行被切成碎片"。

### 结论五：`failed` 三条件保持不动

`replacement_ratio > 0.005`、`control_ratio > 0.02`、`chars == 0` 在 25 份样本里全部为 0 触发，保留即可。

### 已知局限

- 中文样本只有 5 份，且都是同一类文档（简历/证明/说明）。中文论文、中文扫描件的分布仍是空白，阶段 3 之后应按需补样本。
- 图像页样本是 Pillow 生成的清洁页，真实扫描件有倾斜、阴影、噪点，`fast` 模式对二者的表现可能不同（都会是空文本层，但页数与字号分布不同）。
